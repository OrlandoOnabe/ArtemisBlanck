# Definition of Done (DoD)

Uma tarefa da Sprint será considerada **concluída** somente quando atender a todos os critérios definidos abaixo.

## Critérios de conclusão

- [ ] A funcionalidade foi completamente implementada conforme a História de Usuário.
- [ ] Os critérios de aceitação da História de Usuário foram atendidos.
- [ ] O fluxo principal foi testado e está funcionando corretamente.
- [ ] O fluxo alternativo ou de exceção foi testado e está funcionando corretamente.
- [ ] A funcionalidade não apresenta erros que impeçam sua utilização.
- [ ] O código está organizado e segue os padrões definidos pela equipe.
- [ ] A implementação está integrada às demais funcionalidades sem causar erros.
- [ ] As alterações foram versionadas e enviadas ao repositório no GitHub.
- [ ] O código foi revisado por pelo menos um integrante da equipe.
- [ ] A tarefa correspondente foi movida para **Feito** no quadro Kanban.

## Fluxo de conclusão

1. Implementar a tarefa em uma branch de desenvolvimento.
2. Realizar os testes necessários.
3. Fazer o commit das alterações.
4. Enviar a branch para o repositório no GitHub.
5. Abrir um Pull Request para integração com a branch principal.
6. Solicitar a revisão do código por outro integrante da equipe.
7. Corrigir possíveis problemas encontrados durante a revisão.
8. Após a aprovação, realizar o merge com a branch principal.
9. Mover a tarefa para **Feito** no quadro Kanban.
